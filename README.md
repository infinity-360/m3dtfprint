# M3 DTF PRINT — site

Site estático da M3 DTF PRINT (Apucarana/PR): home, vitrine de produtos da Shopee, tour 360° e montador DTF online.

- `index.html` — página inicial (tour 360° em `assets/tour360.jpg`, provisório)
- `produtos.html` — produtos da Shopee com botões "Comprar na Shopee" e "Pedir no WhatsApp"
- `montador.html` — montador DTF: upload, tamanho/quantidade, montagem automática e PNG 300 DPI
- `js/config.js` — WhatsApp, preços por metro, larguras de filme, margens e DPI
- `js/produtos.js` — lista de produtos (id do anúncio da Shopee, preço, foto)
